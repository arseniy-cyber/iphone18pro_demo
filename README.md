# LUMO SITES — BEYOND THE SURFACE / Concept 001

Интерактивный сайт-презентация iPhone 18 Pro Max Burgundy, построенный на модели, предоставленной владельцем проекта.

## Что уже реализовано

- Настоящая исходная модель `.glb` с встроенными текстурами, а не нарисованный силуэт;
- 3D-рендеринг в Three.js, студийное освещение и вращение при входе;
- Прокрутка, управляющая степенью разборки; обратная прокрутка собирает аппарат;
- Защитное стекло, дисплей и внешние детали исходника — отдельные объекты;
- Визуальные концепт-модули аккумулятора, платы, нижней части и индукционной катушки;
- Движение деталей двумя фазами: сначала извлечение, затем перемещение в сторону;
- Маленькие подписи с названиями деталей, прогресс, адаптация для мобильных устройств;
- Типографика: DM Sans + Space Grotesk, акценты Cormorant Garamond.

## Важно о достоверности

Внешняя модель является исходной авторской работой Sketchfab. Внутренние детали **создаются процедурно в коде** как демонстрационная конструкция. Они **не являются точной копией** внутреннего устройства iPhone 18 Pro Max. Для настоящей ремонтной точности нужны проверенные чертежи/разборка и отдельный 3D-моделинг.

Это независимый концепт, не официальный сайт Apple и не интернет-магазин.

## Запуск на компьютере

Файлы нужно открывать через локальный HTTP-сервер, а **не двойным кликом по index.html**, иначе загрузка модели может блокироваться браузером.

1. Распакуйте архив.
2. Откройте терминал / PowerShell внутри папки `lumo-iphone-concept`.
3. Запустите `python -m http.server 8000` (если установлен Python) или `npx serve .` (если установлен Node.js).
4. Откройте в браузере `http://localhost:8000` (если используете Python).

Интернет необходим для Three.js и веб-шрифтов, которые подключены через CDN. Сам файл 3D-модели хранится локально.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `iphone-concept`.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `main.js`, `CREDITS.txt` и папку `assets` с моделью `.glb`.
3. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` → `/ (root)` → `Save`.
4. После публикации откройте ссылку вида `https://USERNAME.github.io/iphone-concept/`.
