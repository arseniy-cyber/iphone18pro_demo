# FORM / iPhone 18 Pro Max Burgundy — Lumo Sites

Вторая версия: светлая арт-дирекция, оригинальный GLB, пересобранные демонстрационные внутренние узлы, корректное по размеру защитное стекло, студийное окружение PBR и управление ракурсом.

## Запуск
1. Распакуйте архив, не перемещая `assets` отдельно от `index.html`.
2. Загрузите всё содержимое в корень нового GitHub-репозитория или ветки проекта. В GitHub Pages выберите `main` / `(root)`.
3. Локально можно запустить `python -m http.server 8000` и открыть `http://localhost:8000`.
4. Нужен интернет для загрузки библиотек Three.js и шрифтов через CDN.

## Управление
- Прокрутка вниз: плавная разборка.
- Прокрутка вверх: обратная сборка.
- Движение мышью: деликатная смена ракурса.
- Перетаскивание мышью или горизонтальное движение пальца по области модели: более широкий обзор.
- `?view=front`, `?view=rear`, `?view=exploded`: фиксированные режимы для проверки внешнего вида.

## Ограничения
Внешняя геометрия взята из предоставленного пользователем GLB, не переизготовлена по CAD-чертежам. Аккумулятор, логическая плата, соединители и внутренние крепления — собственная концептуальная реконструкция, а не проверенная инженерная схема устройства. Фотореализм уровня исходных промороликов Apple не гарантируется. Для точного результата нужны более детальные исходные 3D-ассеты и очная проверка материалов в браузере.

Это независимая работа Lumo Sites, не официальный сайт Apple и не спонсируемый Apple проект.
