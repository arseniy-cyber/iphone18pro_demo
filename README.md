# FORM — iPhone 18 Pro Max Burgundy / Lumo Sites

**V7 — отдельная сборка для проверки в браузере.** Независимая интерактивная художественная концепция; не официальный сайт Apple.

## Что изменено

- Новый экран загрузки: минималистичный силуэт Apple, две тонкие анимированные орбиты, заголовок, реальная полоса загрузки GLB. Добавлен текстовый таймаут на случай ошибки загрузки.
- Объёмный WebGL-дым пересобран в форме **плавно движущихся клубов**, а не плоских размытых пятен. Оттенки графитово-серые, с мягкими краями; облака расположены в глубине сцены по бокам телефона, под текстом лежат светлые зоны для читаемости.
- Защитное стекло: скругление **R≈12 мм** по измеренной передней поверхности GLB; ширина 73,03 мм и высота 158,487 мм, прозрачная поверхность и тёмная окантовка 0,9 мм.
- Внутренний камерный блок убран от лишних дублирующих колец; задние объективы и несущий модуль движутся как одно целое.
- При полной разборке стекло, экран, аккумулятор и плата разнесены по ширине без наложения при прямом фронтальном обзоре. Камера отдаляется по мере разборки, чтобы композиция помещалась на экране.
- Задняя крышка движется **вдоль оси корпуса**, без бокового смещения. Для обзора сзади в конце разборки она становится полупрозрачной, чтобы не заслонять внутренние детали.
- Текст и светлый редакционный дизайн V6 сохранены. Скриншот Lumo Sites на экране очищен от панелей браузера.
- Добавлен сброс кеша `?v=7` для новых файлов CSS, JS, фонового дыма и изображения дисплея.

## Файлы для GitHub Pages

Загрузи в **корень** существующего репозитория `iphone18pro_demo`, заменив только:

- `index.html`
- `main.js`
- `style.css`
- папку `assets/` целиком, включая `iphone18-burgundy.glb`, `smoke-volume-64.raw` и `screen-lumosites.jpg`

`LICENSE_MODEL.txt` и `README.md` можно хранить в репозитории как справочные файлы. Не нужно удалять репозиторий или менять настройки GitHub Pages.

## Управление

- Прокрутка вниз: послойная разборка.
- Прокрутка вверх: сборка.
- Перетаскивание мышкой: свободный обзор по горизонтали и вертикали.
- На телефоне: горизонтальное движение пальца меняет ракурс; вертикальное прокручивает сайт.

## Проверка и ограничения

Синтаксис JS, состав файлов, адаптивность HTML/CSS для 390 px и 1440 px и отсутствие горизонтальной прокрутки проверены. При этом полноценно запустить внешние Three.js-модули через локальный Chromium в этой среде не удалось из-за ограничений доступа к сетевым ресурсам, поэтому визуальный результат именно WebGL-дыма и 3D-вращения нужно подтвердить на опубликованной странице.

Внутренности остаются 3D-реконструкцией по визуальным референсам, а не точной инженерной CAD-моделью устройства.
